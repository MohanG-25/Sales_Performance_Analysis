# Sales Performance Analysis Using Excel, SQL and Python

## Project Overview
This project analyzes retail sales data to identify business trends, product performance, regional profitability, and discount-related losses.

The project combines Excel, SQL, and Python to perform data analysis and generate meaningful business insights.

## Tools & Technologies
- **Excel:** Initial data exploration and reporting
- **SQL:** Business queries and aggregations
- **Python:** Data cleaning, analysis, and automation
- **Pandas & NumPy:** Data manipulation
- **Matplotlib & Seaborn:** Data visualization
- **Jupyter Notebook:** Interactive analysis

## Key Analysis Areas
1. Overall sales and profit performance
2. Monthly sales trends
3. Top 10 products by sales
4. Region-wise sales and profitability
5. Category-wise profit margins
6. High-discount and loss-making products

## Python Implementation
- Cleaned and processed the retail dataset using Pandas.
- Performed exploratory data analysis.
- Generated visualizations to identify business trends.
- Exported analysis results into reusable CSV reports.

## Project Structure
- `data/` – Dataset
- `notebooks/` – Python analysis notebook
- `sql/` – SQL queries
- `reports/` – Generated analysis reports

## Business Value
The analysis helps identify high-performing products, profitable regions, category-level performance, and products affected by excessive discounts.

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install pandas numpy matplotlib seaborn jupyter openpyxl`.
3. Open `notebooks/sales_analysis.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells sequentially.
